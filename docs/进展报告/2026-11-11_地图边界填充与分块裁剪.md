# 地图边界填充与分块裁剪

小地图设 `fill_color=(4,8,12)`，画布先填此色，再执行 World.draw。旧版视口外像素仍变为默认天空色 `(135,255,255)`；分块超出有限地图的部分覆盖了填充色，已有配置功能无效。

现在按非循环轴限制绘制区域，循环轴仍正常重复；只绘制实际地图范围内的分块，保留调用方的裁剪区域。部分分块在非整数缩放时可能向边界外多采样一像素，现延展最边缘原生像素后按世界边界裁剪，避免天空细线渗入地图边缘。

实测有限/横向循环/纵向循环/双向循环四种组合，视口外颜色按各轴正确显示。64×36 小世界、视野 200 的首帧从绘制 **84 块降至 4 块**，本机约 **74ms→7ms**。时间受负载影响，数量变化可稳定复现。

原始前后数据：`evidence/2026-11-11_world_background_before.json` / `..._after.json`。旧版固定为 `dfb1ed9`：

