# 界面与体验改进

## 基线

`evidence/interface/before/` 保存模块化后、视觉调整前的主页、地图列表、方块和 buff 图鉴截图。当前服务器没有中文系统字体，旧 `SysFont` 探测把不存在的字体也当成成功回退，导致标题和提示成为方框。主页截图为入场初帧，菜单尚未全部显示；后续验收同时捕获稳定帧。

## 字体修复

- 内置未修改的 Fusion Pixel 12px Proportional zh-Hans（上游 2026.11.10 发布），随项目离线分发，附 OFL 及各来源授权文本。来源和哈希见 `assets/fonts/README.md`。
- 中英文统一使用像素字形，不依赖用户安装中文字体；缺少内置字体时，系统回退只接受实际存在的字体文件。
- 动画文本的阴影跟随文字透明度，修复文字完全透明时仍出现不透明黑影。
- 回归验证中文关键字形存在、透明文本不改变画布；实际截图已确认地图列表中文可读。

接下来统一主页、地图选择、设置和帮助交互；菜单布局、显示信息和鼠标命中必须使用同一份几何定义，避免只改外观导致点击错位。

## 主页与地图选择

- 主页改为清晰的四项导航和原生像素场景；菜单文本由 JSON 加载，绘制与鼠标命中共享布局，支持窗口缩放和留黑边后的准确点击。界面动画不消耗地图生成的全局随机状态。
- “世界图鉴”直接进入已有方块图鉴，不再和“开始游戏”重复进入同一列表。
- 地图选择显示真实中文名称、玩法标签、尺寸、循环类型和简短介绍。右侧预览是离线生成的开局场景；选择地图不会加载/生成世界，8 项预览 LRU 有界缓存。
- 支持滚轮、方向键、Home/End、PageUp/PageDown、双击启动和可点击的编辑/图鉴/开始按钮；长名称省略，不覆盖相邻列。
- 新界面暴露了旧重命名只改目录而不持久化显示名的问题：现在保存显示名，失败时回滚目录，并拒绝无效目录名。测试使用临时目录，不修改实际地图。

验证：**85 项自动回归通过，14.040 秒**；包含“不生成地图”的选择界面检查、缩放命中、预览缓存上限、名称持久化和所有原有主循环场景。主页和列表已检查实际截图。主题色保存在 `data/theme.json`，图案仍使用像素绘制。

## 设置、启动和操作指引

- 设置页统一像素面板；支持鼠标调节/拖动音量、点击帧率按钮和返回按钮，原键盘操作保持可用。只点击文字不会误改音量，释放鼠标后结束拖动。
- 非预设帧率（如 70 FPS）向下/向上调整为 60/90，达到上下限不突然循环到另一端；性能评估标注为参考评估，并能响应退出。
- 资源就绪后立即允许确认进入主页，移除与实际加载无关的 2.8 秒等待；修正未实现奖励及上岸条件的误导提示。
- 游戏内增加 `H` 操作指南，数据来自 `data/controls.json`；打开时暂停位置、计时和状态更新，`H/Esc` 关闭后继续。不会用查看说明消耗关卡时间。

真实主循环验证设置暂停、指南暂停/恢复、启动立即就绪及原流程；设置单元检查缩放后点击/拖动/释放和帧率边界。完整 **87 项通过，14.534 秒**，设置与指南截图已人工查看（SDL 离屏截图，不代表实体输入/音频验收）。
