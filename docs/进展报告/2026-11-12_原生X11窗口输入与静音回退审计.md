# A72：原生X11窗口、输入与静音回退

本轮扩大运行证据，不改变游戏玩法、物理或地图。此前SDL dummy的事件/会话测试不能证明窗口后端工作，因而用独立Xvfb、SDL x11和XTest原生输入实际运行`GameApp.run()`。当前完整回归仍为A71的e54bcd2：271项通过389.118秒；本轮新增原生流程与17项界面定向回归，不重复宣称一次新的全量结果。

## 环境与隔离

服务器没有DISPLAY、窗口管理器或现成Xvfb/xdotool。使用系统已配置Ubuntu22.04软件源下载xvfb、xdotool、libxdo3，仅解包到`/data/Users/zrh/.cache/pixel-roamer-audit/x11`，没有全局安装。包版本和SHA256见[环境原始记录](evidence/2026-11-12_native_x11_environment.json)。独立服务使用`-displayfd 1 -screen 0 1920x1080x24 -nolisten tcp -ac`；本轮分配`:0`，执行其他轮次时以实际输出为准。

脚本[scripts/audit_native_window.py](../../scripts/audit_native_window.py)只在原生呈现完成后读取状态和调度xdotool动作，保留实际SDL队列、`pygame.key.get_pressed()`和生产主循环。原生焦点目标是本测试创建的xmessage窗口。截图来自实际窗口呈现surface；无合成SDL按键替代。这是虚拟X11桌面验证，仍未覆盖实体显示、桌面合成器、实体声卡及中文输入法。

| 流程 | 断言及结果 |
| --- | --- |
| 启动、主页、鼠标进入/退出设置 | 真实窗口获得焦点，原生Esc跳过启动过渡，点击设置及返回均符合页面状态 |
| 留黑边与点击换算 | 原生窗口800×600，scale0.5，偏移(0,75)，按主页按钮实际逻辑坐标换算后成功进地图列表 |

| 帮助/设置暂停 | 两段各约0.6秒等待中，游戏计时及角色位置逐值保持，Esc恢复 |
| 世界窗口变宽 | 原生1000×500，scale5/9，偏移约(55.556,0)，窗口surface与应用尺寸一致 |

有声API可用但输出到dummy：源码快照6afa360，11.068850秒、511帧，24/24步骤通过、错误为空，[完整原始数据](evidence/2026-11-12_native_x11_formal.json)。已查看[800×600主页](evidence/2026-11-12_native_x11_formal_home_800x600.png)及[1000×500世界](evidence/2026-11-12_native_x11_formal_world_1000x500.png)，留黑边方向符合比例。320×180仅确认防止无效尺寸及崩溃，不称为推荐阅读尺寸。

故意指定不存在的SDL音频驱动：源码快照739aac8，`mixer=None`，仍11.063671秒、564帧，24/24步骤通过、错误为空。[无音频原始数据](evidence/2026-11-12_native_x11_no_audio.json)、[运行日志](evidence/regressions/native_x11_no_audio.txt)保留。两快照游戏代码相同，差别是证据归档提交；音频恢复可用性与声卡实际输出仍是不同范围。

相关主页、设置、编辑器、焦点生命周期、应用流程共17项在12.807秒通过，[回归日志](evidence/regressions/native_window_existing_ui.txt)。本轮没有发现需要修改生产代码的原生窗口故障。

## 开发失败与修正

初次和第二次分别误用不存在的`World.id`、`Player.x/y`；修正为`map_id`和`get_center()`，见[初次](evidence/2026-11-12_native_x11_initial.json)、[第二次](evidence/2026-11-12_native_x11_second.json)。第三次用PID查找Xt xmessage失败，因为它没有发布_NET_WM_PID，改为私有窗口标题：[原始记录](evidence/2026-11-12_native_x11_third.json)。第四次xdotool把负数当命令选项，补入`--`选项终止符：[记录](evidence/2026-11-12_native_x11_complete.json)中`completed=false`；文件名沿用当次名称，不能据此判断通过。以上均是测试器错误，不是游戏缺陷，原始失败未覆盖。

## 重现与下一步

在独立X11显示上配置工具目录后执行：

```bash
DISPLAY=:0 SDL_VIDEODRIVER=x11 \
LD_LIBRARY_PATH=/data/Users/zrh/.cache/pixel-roamer-audit/x11/usr/lib/x86_64-linux-gnu \
python3 scripts/audit_native_window.py \
  --xdotool /data/Users/zrh/.cache/pixel-roamer-audit/x11/usr/bin/xdotool \
  --output /tmp/pixel-native-result.json
```

无音频变体增加`SDL_AUDIODRIVER=pixel-roamer-unavailable`。常规变体脚本默认SDL音频dummy。需要xmessage及私有显示；不在他人桌面注入输入。
