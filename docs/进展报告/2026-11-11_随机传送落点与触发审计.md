# 随机传送落点与触发审计

固定目标门之外，末影符文（301）与混沌裂隙（358）走另一条分支，直接给坐标加随机偏移，没有碰撞、边界或持续触发保护。有限数值压力检查无法发现角色已经嵌在墙里。

## 实测与修复

在含地面的 30×30 世界，从正常接触位置激活每种符文，分别测试随机种子 0～999：

| 方块 | 原不安全落点 | 修复后不安全落点 |
|---|---:|---:|
| 末影符文 | 164 / 1000 | 0 / 1000 |
| 混沌裂隙 | 691 / 1000 | 0 / 1000 |

保留原有偏移范围与随机性，复用安全传送放置；每次最多尝试 32 组偏移，没有可容纳角色的位置就留在原处。随机门与固定门共用进入接触锁，避免站在符文上每步重新抽样、同位置返回递归或持续抖动。成功传送也清理旧动作并重新采集目标环境。

原始前后数据为 `evidence/2026-11-11_random_portals_before.json` / `..._after.json`，可运行：

```bash
python scripts/audit_random_portals.py --output /tmp/random-portals.json
```

## 验证

实际方块激活 2000 个种子，均不嵌入实体、不越界、不超过原偏移范围，绝大多数样本实际移动，避免靠关闭功能通过测试。密闭空间故意给出不可用偏移，恰好完成最多 32 次尝试后保持原位；随后持续接触 120 次不再重复计算。零偏移返回同一符文不递归，接触结束后解锁；非法、NaN、Infinity 和超大范围不崩溃。

新增 4 项回归，完整 **142 项通过，41.968 秒**。这里的“安全”指可容纳角色的几何与世界边界；没有把随机传送改为避开所有危险地形，合法危险区域仍保留原有游戏风险。
