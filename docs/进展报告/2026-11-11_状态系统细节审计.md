# 状态系统细节审计

## 复现与修复

| 原有功能 | 修复前问题 | 修复后的规则 |
|---|---|---|
| 短时着火 | 0.1 秒效果未到全局 0.25 秒 tick 就消失，无伤害 | 按实际活跃时长积分 |
| 同时长伤害 | 1 秒长帧漏 tick，1 秒效果先删除再计伤害；结果依帧率变化 | 按到期边界拆分时间，完整覆盖短帧、长帧及最后一段 |
| 临时免疫与伤害并存 | 效果处理顺序可能保护整帧或完全不保护 | 只在免疫实际存在的时间段阻挡伤害 |
| 流血 | 当前生命百分比损失随帧划分变化 | 按指数衰减积分，分帧后结果一致 |
| 叠层 | UI 显示层数但持续伤害/属性数值未使用层数 | 持续数值按层数处理，百分比线性累加且不产生负倍率 |
| 净化周期 | 计时器挂在角色上，移除并重加效果会继承旧进度 | 周期计时归属于 buff 实例 |
| 护盾伤害返回值 | 护盾吸收后只返回剩余伤害；过量伤害被当成实际伤害 | 返回实际减少的护盾及生命总量，封顶于可用资源 |
| 荆棘/嗜血 | 用请求伤害计算反弹/吸血，过量击杀会放大收益 | 使用实际损失量 |
| 耐火 | 描述免疫火焰/熔岩，但代码未执行 | 着火、直接火伤、熔岩接触均受耐火保护 |
| 破甲 | 负面效果错误检查攻击者，反而增强携带者攻击 | 检查受击者，忽略其抗性和减伤，保留独立免疫/穿盾规则 |
| 护盾恢复上限 | 已有护盾高于该恢复源上限时反被扣除 | 恢复操作不减少已有护盾 |

新增测试初次执行有 14 个断言失败。修复后状态专项 14 项及所有其他回归通过：**68 项，13.259 秒**。错误 dt、非有限伤害输入被拒绝，防止 NaN/无穷传播。

## 模块边界

`status_effects.py` 承担时间推进和属性修正，`BuffInstance` 持有自己的周期计时；`Creature` 通过薄方法调用，并统一处理实际生命/护盾损失。该拆分减少角色文件中的重复数值逻辑，为后续数据迁移提供稳定接口。

连续效果的每秒数值按活跃时间计算，时间推进在各个到期点分段。周期性净化和困倦仍保留周期机制；同帧新增的效果不会被扣除其创建之前的时间。叠层不是新玩法，按原数据已有 `max_stacks` 和界面显示补齐实际数值。

## A4：不依赖碰撞的接触效果计时

继续审计发现幻影、混乱和触发冷却依附于碰撞调用；晕眩或飞行跳过碰撞时，这些效果不会按时结束。现在所有状态计时在 `tick_buffs()` 阶段统一推进，物理是否运行不会改变持续时间；暂停/指南仍停止状态时钟。飞行跳过碰撞时显式清除水面、梯子、地表倍率等旧接触状态。

新增无任何碰撞调用的到期断言，以及实际主循环的晕眩/飞行边界检查；原直接碰撞测试改为使用与运行时一致的“状态时钟→物理/接触”顺序。完整 **91 项通过，15.426 秒**。
