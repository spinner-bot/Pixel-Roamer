# 控制动作入口一致性

实际场景：角色 (6.1,5.7) 接触梯子，施加晕眩，再按 W。旧主循环虽然跳过物理更新，事件处理仍调用攀爬居中，将 X 移到 5.5；因此“无法移动”的晕眩可从另一条输入路径被绕过。

在跳跃、开始攀爬、攀爬速度设置入口统一补齐相关控制限制。晕眩不能跳跃或攀爬；压制仍只禁止跳跃，不禁止攀爬；铁意按既有规则覆盖晕眩与压制。强制允许空中起跳的参数不再绕过控制状态。未把定身扩展为禁止跳跃，因为已有说明明确只禁止左右移动。

新增四项动作 API 回归；真实主循环另增加晕眩期间按 W 不移动、状态解除后不补执行旧按键、重新按 W 才开始攀爬。可用与缺失音频设备的两条导航流程都执行该场景。
