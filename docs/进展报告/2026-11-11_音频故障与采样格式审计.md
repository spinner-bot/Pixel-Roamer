# 音频故障与采样格式审计

## 无设备崩溃与重试失效

复现：`SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=not_available python3 -c 'import pygame,sfx; pygame.init(); sfx.play_jump()'`。旧版工厂先创建 Sound，再检查混音器，抛出 `pygame.error: mixer not initialized`；失败重试又因 `_initialized=True` 提前返回，设备恢复后仍可能无声。

修复后先确认设备可用，再合成和播放；失败时跳过声音，保持游戏运行，按已有 60 秒退避重试；外部恢复有效设备时立即重建声道。音乐合成也遵守设备可用状态，暂停而非继续构造无效 Sound。

回归覆盖所有七种公开音效、音乐请求/更新/停止、失败退避及恢复。完整实际主循环在无音频设备环境下执行全部 15 张地图导航、暂停、控制、死亡和胜负场景，确认没有音频设备也能继续游戏。

## PCM 声道错误

合成器输出 16-bit 单声道字节，混音器配置双声道；直接传入后，相邻单声道样本被误读为 L/R，时长减半，音高翻倍且左右波形不一致。

| 音效 | 设计时长（秒） | 修复前实测 | 修复后实测 |
|---|---:|---:|---:|
| 跳跃 | 0.10 | 0.049977 | 0.100000 |
| 拾取 | 0.06 | 0.029977 | 0.060000 |
| 受伤 | 0.15 | 0.074966 | 0.149977 |
| 死亡 | 0.35 | 0.174966 | 0.349977 |
| 检查点 | 0.25 | 0.124989 | 0.249977 |
| 胜利 | 0.50 | 0.249977 | 0.500000 |
| 点击 | 0.03 | 0.014966 | 0.029977 |

现在将每个单声道样本复制并交错为 L/R。测试确认 440 Hz 音符持续一秒，左右样本完全相同，正向过零次数与 440 相差不超过 1；音乐模式时长也保持一秒。部分毫秒误差来自整数采样截断。

## 声道抢占和重复播放

复现：先播放死亡声，再播放背景音乐，再播放死亡声；音乐使用声道数 1→0，背景音乐被抢断。现在八条效果声道与两条音乐声道分离，音乐可交叉淡入淡出；同一曲目重复请求不再叠加播放或不断重新开始。测试确认关键音效不会抢占音乐，连续四次请求同曲仍只有一个实例。

完整回归 **111 项通过，31.689 秒**；其中包括真实 SDL dummy 混音器、失败驱动独立进程、PCM 字节与频率检查和无设备主循环。软件验证没有代替实体扬声器、耳机、声卡切换与实际听感验收。
