# 像素素材精修与缓存验证

## 范围与复核

12 种常用方块采用原生 16×16 纹理：岩石、冰、黏土、沙、水、梯子、泥土、草地、原木、木板、砖块、树叶。58 个 buff 保留原有语义，统一类别边框，并重绘恢复、护盾、迅捷、轻身、活力、耐火、着火及三种免疫图标。没有增加玩法或改变碰撞、摩擦、伤害、时长等字段。

已人工查看 [方块对照](evidence/art/blocks_before_after.png) 和 [buff 对照](evidence/art/buffs_before_after.png)，每项左侧为原素材、右侧为新素材。纹理生成固定随机种子；`scripts/refine_pixel_art.py` 从已提交的 `e53ea03` 读取旧素材，重跑不会重复加框。运行时只读取 JSON，无需 git 或生成工具。

迁移前哈希不覆盖；有意修改的像素单独记录于 `catalog_art_overrides.json`。新增 `catalog_non_art_baseline.json` 独立锁定所有非美术字段，359 个方块和 58 个 buff 全部保持一致。

## 渲染与性能

原分块纹理每格只有 10px，新 16px 细节会先被缩掉，现提高到 16px。基础缓存上限由 128 块调整为 64 块，满缓存为 64 MiB；缩放缓存仍有独立 64 MiB 上限。提高采样质量增加单块生成成本，需在后续运行审计中继续量化。

HUD 原本每帧执行图标矢量命令。现在每个图标/尺寸首次光栅化，之后复用，最多保留 128 个变体；测试确认连续 120 次请求仅执行一次光栅化，多尺寸请求不会无限增长。

素材改动后完整回归 98 项通过；新增 HUD 缓存专项通过。后续继续执行包含主循环、全地图、全方块的完整运行审计。SDL dummy 截图和模拟不能替代实际显示器与操作手感验收。
