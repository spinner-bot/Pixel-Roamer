# 渲染数值与对齐审计

## 视野半径单位

相机 `scale` 已经表示像素/格，旧视野受限又乘 24。400×300、10 像素/格、半径 2 格时，本应只看清 20 像素半径，旧代码实际是 480 像素，覆盖整个画面，效果看起来无效。现在只换算一次；在 10/20/40 像素每格的三个倍率下检查中心正常、半径外变暗。

超大半径直接保留完整视野，不分配超大遮罩；清明正确抑制失明与受限视野。世界滤镜在角色之前绘制，使角色和 UI 保持可识别。

## 发光透明度

旧加色使用原始 RGB=255/240/180，混合时忽略 6～27 的 alpha，导致白色圆盘。改为预乘光强后再 RGB 加色：背景 40 的中心提升到不超过 70，而不是直接达到 255。光晕最多缓存四个尺寸，遮罩复用当前视口尺寸。

## 时装对齐与动画时钟

旧统一偏移 `高度×0.22` 不适合三套不同透明留白的时装，产生脚部悬空/埋地，翻面也可改变可见中心。现在以缩放后实际 alpha 包围盒的底边和中心锚定到物理脚部，三套时装、三个尺寸及左右翻面共 18 个组合均检查。

动画不再每长帧最多前进一帧；按完整时间步推进，0.75 秒、五个 0.15 秒和七十五个 0.01 秒结果一致。更换状态/时装重置动画周期，单帧状态归零，暂停不推进。渲染和状态逻辑分离在 `visual_effects.py`、`costumes.py` 和 `WorldView` 中。

本阶段添加视野/清明/发光/大半径四项，以及脚部对齐、动画分帧两项回归；其余流程继续通过。后续素材精修会保留这些几何及数值断言。
